## 核心差异化

### 1. FigTree 注解注入

FigTreeKit 是**唯一**能程序化注入 FigTree 特定注解到 Nexus 文件的 Python 库。通过研究 FigTree 1.4.4 的公开 Java 源码（`FigTreeNexusExporter.java`）实现。

### 2. 分类学感知分析

FigTreeKit 独特地支持两种格式的分类学提取：
- **格式 A（嵌入式）**：`_d_Bacteria_p_Cyanobacteriota_...` 编码在标签中
- **格式 B（表格）**：`d__Archaea;p__Thermoproteota;...` 来自映射文件
- **混合模式**：同一棵树中两种格式，可配置优先级

### 3. 深度输入验证

### 4. 非变异导出

FigTreeKit 的导出过程不会修改内部树内容（`_tree_content`）。注解在写入前解析到本地副本，因此同一 `FigTreeStyler` 实例多次调用 `export()` 不会产生副作用，输出结果始终一致，保证自动化流水线的可复现性。

### 5. 自检模式

`figtreekit --self-test` 运行 11 项内置检查，覆盖依赖版本、解析、分类学、单系群逻辑等。

## 复现对比

如需验证以上声明，可运行：

```bash
# 安装所有工具
pip install figtreekit dendropy ete3 biopython

# 运行 FigTreeKit 自检
figtreekit --self-test

# 运行 FigTreeKit 基准测试
python benchmarks/performance.py

# 运行 FigTreeKit 测试套件并查看覆盖率
pytest test/ --cov=figtreekit
```
